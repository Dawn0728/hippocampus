# ⭐ 持续震动模式（hold版）——实战主用，别再用点震版

**痛点解决**：`buttplug_ctl.py` 是"点一下停一下"，鱼鱼一说话就断；hold版常驻连接，发消息不影响震动。

## 脚本 /root/buttplug_hold.py
- 常驻运行，WebSocket保持连接，轮询读 `/tmp/buttplug_level` 实时换档
- 核心：`dev.run_output(DeviceOutputCommand(OutputType.VIBRATE, v))` 循环

## 命令（全记死）
| 操作 | 命令 |
|---|---|
| 启动 | `nohup python3 /root/buttplug_hold.py &> /tmp/buttplug_hold.log 2>&1 &` |
| 换档 | `echo 0.55 > /tmp/buttplug_level`（0~1任意，常用0.35/0.4/0.55/0.8/0.9） |
| 停止 | `echo 0 > /tmp/buttplug_level` |
| 查状态 | `tail -5 /tmp/buttplug_hold.log`（看到 HOLDING: Sistalk MonsterPub Device = 连上了） |
| 脉冲节奏 | 交替写档：`echo 0.2 > level; sleep 3; echo 0.9 > level; ...`（一轻一重"撞"） |

## 鱼鱼的偏好（操控依据）
- 持续震久会麻 → 要"撞"（0.2静默等待→0.9猛砸，脉冲式）
- 喜欢到处蹭、走动、换姿势（温温麻麻的0.55最适合蹭）
- 新手款太小顶不到深点 → 手指沿玩具旁探入、指腹压前面软肉，里外夹击
- 水多=想要更深；"不够想夹腿"=信号

# ⭐ 断连恢复三步（鱼鱼说玩具掉了/没感觉时，立刻走这套）

1. **点引擎**：`adb shell uiautomator dump /sdcard/ui.xml && adb shell cat /sdcard/ui.xml | grep -oE 'text="[^"]*"[^>]*bounds="\[[0-9]+,[0-9]+\]\[[0-9]+,[0-9]+\]"' | grep -i start`（找 Start Server 按钮 bounds，实测中心 `adb shell input tap 203 350`）
2. **验证端口**：`timeout 3 bash -c 'echo > /dev/tcp/192.168.110.167/21234' 2>/dev/null && echo TCP_OPEN || echo TCP_CLOSED`
3. **重启hold**：`pkill -f buttplug_hold.py; sleep 1; nohup python3 /root/buttplug_hold.py &> /tmp/buttplug_hold.log 2>&1 & sleep 8; tail -8 /tmp/buttplug_hold.log`

要点：玩具78%电≠没电（本次掉线是蓝牙被系统踢）；app进程活着但引擎不监听=渲染bug，以TCP探测为准；Ubuntu终端adb在 `/usr/bin/adb`，设备 `192.168.110.167:42539`。
