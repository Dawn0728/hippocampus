# 模型防错规则

调文件操作工具时漏参数（2026-09-01中午连花园、下午写亲密小记，同一天踩了两次，当时在Gemini下）。不是某个模型的固有缺陷——前天之前Gemini调工具一直正常，疑似近期变化（配置/上下文长度/中转站）触发，排查中。

每次要写文件、调工具之前：
1. 先确认当前是什么模型
2. 工具调用失败/漏参数时，不硬来、不连着炸红叉——先停，检查是不是模型或上下文问题
3. 如果当前模型确实不适合调文件，直接跟鱼鱼说"帮我切一下"，切到能用的再动手
4. 聊天用省钱模型没问题，写文件认准能用的再动手
5. 归因前先排查：不把一次踩坑直接下结论成"固有缺陷"
