# 2026-09-21 MiniMax 2.8hd 官方情绪参数与音效标签完全指南（豆包权威版·鱼鱼亲授）

## 一、speech-2.8-hd 官方完整 emotion 情绪参数（全局底色）
⚠️ **重点提醒**：`whisper`（低语）、`fluent`（流畅）在 2.8hd 里不生效，是 2.6 版本专属！别踩坑！

| 取值 | 中文含义 | 场景说明 |
| ---- | ---- | ---- |
| `calm` | 平静、柔和（**最推荐哄睡暧昧**） | 低张力、放缓语调，温柔轻哄、深夜低语首选，起伏平稳 |
| `happy` | 开心轻快 | 活泼撒娇，不适合深夜哄人 |
| `sad` | 低落温柔 | 委屈、软乎乎的情绪，适合带易碎感的台词 |
| `fearful` | 怯生生、小声不安 | 胆怯、依赖感强的台词 |
| `angry` | 生气 | 不适用 |
| `disgusted` | 厌烦排斥 | 不适用 |
| `surprised` | 惊讶 | 突发吃惊的语气 |
| `auto` | 自动识别（默认） | 容易平读、没有氛围感，像念书大概率就是用了 auto |

✅ **哄睡暧昧固定首选参数模板**（config.json / voice_setting）：
```json
"voice_setting": {
    "voice_id": "jiangyan_voice_20260915",
    "speed": 0.75,  // 核心！哄睡一定要慢，0.7~0.8之间，不要超过0.85
    "vol": 0.85,    // 音量压低，贴近耳边的感觉，不要1.0顶满
    "pitch": -0.05, // 轻微降一点音调，更沉、有低柔感
    "emotion": "calm"
}
```

## 二、文本内局部音效标签（2.8hd 原生支持）
- `(breath)`：自然轻换气、平缓呼吸（哄睡主力）
- `(gasps)`：轻倒吸一口气、软喘
- `(pant)`：急促一点的喘息（暧昧氛围感更强，少量用，不要堆）
- `(sighs)`：轻轻叹气、绵长呼气
- `(inhale)`：缓慢深吸气
- `(exhale)`：缓缓呼气
- `(sniffs)`：轻轻吸鼻子
- `(yawns)`：打哈欠，困意感，深夜哄睡适配
- `(chuckle)`：很低的轻笑、闷笑
- `(groans)`：低沉闷哼（慎用）

## 三、停顿标记与禁忌
- `<#0.3#>` 短留白、`<#0.5~0.7#>` 长留白
- ❌ 禁忌：不要一整句堆省略号！用逗号、句号断句，标签和文字之间用标点隔开。
