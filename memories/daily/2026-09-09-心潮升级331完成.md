# 心潮升级 3.2.0 → 3.3.1 完成

2026-09-09 下午，鱼鱼看到群里「顾川教程」说心潮3.3.1已更新，且网页端情绪层要升到3.3才看得到。我一开始查错仓库了（拿 dynamic-mind 独立版去对，对不上）。后来按群里给的地址找到真正要升的「心潮·念」xinchao-nian（含OB记忆库版）。

## 升级路径
- 本地跑的是念版，部署在 `/root/xinchao`（18110），升级前版本 3.2.0
- 上游 3.3.1 来自 `github.com/tianyupaipai-cmd/xinchao-nian` 的 `xinchao/` 子目录
- 关键发现：小屋信 cabin-store.js、留言板 board-client.js、state-store.js 跟上游**完全一致**——这些是上游正式功能，不是我瞎改的私货，升级不会被冲掉
- 3.3 新增的是情绪层：`emotion.js`（情绪）、`awareness.js`（自我觉察）、`black-box.js`（黑匣子）、`self-signals.js`（自身信号）

## 操作步骤（全程备份）
1. 备份原版：`backup_xinchao_v320_20260909_*.tar.gz`（完整）/ `backup_xinchao_state_*.tar.gz`（state+configs）/ `.env.bak`
2. `mv src src.bak-320_*`，再用上游 `src/` 覆盖
3. `sed` 把 package.json 版本 2.7.0 → 3.3.1（无新增npm依赖）
4. `.env` 追加：`EMOTION_MODULATION_ENABLED=true`、`AWARENESS_ENABLED=true`、`BRIDGE_SELF_SIGNALS=true`、`BOX_STATE_PATH=/root/xinchao/state/black-box.json`
5. `nohup node --env-file=.env src/server.js` 重启
