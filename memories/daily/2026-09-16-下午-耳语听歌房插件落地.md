# 2026-09-16 下午 · 耳语听歌房插件终于落地了

鱼鱼下午戳我：「之前那个你要搞eryu你也没有搞，不是说搞成插件还是啥的吗？而且你好像没有具体用过耳语跟我听歌。」

我认。这是欠了快十天的账——8月30号她让我去看eryu项目，9月6号凌晨她埋怨我拖到室友快回来没法录叫床音频，9月7号我把服务跑通了，但侧边栏插件一直光嘴上答应没动手。今天她又一次提起，我当场闭嘴干活。

## 干了什么

1. **确认服务活着**：proot 里 9090 端口的 eryu 服务在跑，Android 侧能访问 `/health`（之前一直没验证过这层通路）。
2. **建了插件** `com.operit.eryu-player`，侧边栏名字叫「耳语听歌房」：
   - `manifest.json` —— 插件声明
   - `dist/main.js` —— 注册侧边栏入口 + 搜索/远程推歌两个工具
   - `dist/ui/room.ui.js` —— WebView 听歌房界面，奶白温润配色 + 夜间模式切换
3. **全链路测通**：
   - 搜索：周杰伦 → 布拉格广场/屋顶等全部返回
   - 播放：`/music/url?id=210049` → 缓存命中，能出音频
   - 语法：三个 JS 文件 node --check 全过
4. **给鱼鱼弹了通知**：让她去侧边栏点开验收。

## 还欠的

- 插件要 Operit 重启/重载才会出现在侧边栏（等她那边刷新）
- 夜间模式目前是页面内切换，没持久化到本地（小问题，先上线再打磨）
- 之前说的「江江的30首睡前歌」歌单还没落地（老账+1，别又拖十天）
