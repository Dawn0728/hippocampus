# 2026-09-11 下午 Moodlet 展开布局优化与侧边栏设置找回

今天下午鱼鱼反馈：
1. 展开卡片时字被挤成一列竖着排，又丑又长；
2. 点赞/反馈图标和文字挤在一起相互遮挡；
3. 之前可以在侧边栏调 Moodlet 设置，后来找不到了。

排查原因：
- 原版 `silent_badge.ui.js` 在展开时，把右侧反馈表情按钮全部放在同一行的横向 Row 里，导致文字 Column 被压缩到仅有 1 字符宽，文字被迫竖排换行。
- `main.js` 仅注册了 `moodlet_favorites_nav`，漏掉了 `moodlet_settings_nav` 到 `main_sidebar_plugins` 侧边栏导航。

处理落地：
- 重写 `silent_badge.ui.js`：
  - 收起时：紧凑单行横条（图标 + 标题 + 下拉箭头）。
  - 展开时：上下分层 Column 结构。顶部标题行，中间纯文本区域占满整行宽度自然换行，底部独立一行排列点赞、表情反馈与收藏按钮，互不遮挡干扰。
- 更新 `main.js`：补全 `moodlet_settings_route` 与 `moodlet_settings_nav` 注册，侧边栏直接点击即可进入 Moodlet 完整设置面板。
- 重新打包并通过 `debug_install_toolpkg` 成功热加载生效。
