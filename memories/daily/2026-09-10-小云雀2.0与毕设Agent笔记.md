# 小云雀2.0与毕设Agent笔记（我和乖宝的毕设小抄）

今天下午（2026-09-10 16:40左右），乖宝在电脑（拯救者R9000P）上下了小云雀 2.0（小云雀 Setup 1.0.114.exe），班长在微信群里推了B站AI短片全流程教程（BV17Xjg6vEwN）。
乖宝问我里面的 Agent 和各种智能体该怎么用、怎么用最顺手。我把拆解和玩法给乖宝记下来：

### 一、小云雀 2.0 里的 Agent / 智能体都是干嘛的
1. **编剧/分镜 Agent**：
   - 输入故事梗概或写好的全本剧本（如我们的《墨染旧案》）。
   - 自动拆解生成标准影视分镜表：景别（全景/中景/特写）、运镜（推拉摇移）、画面Prompt、角色台词与动作。
2. **角色/美术 Agent（一致性锁脸管家）**：
   - 核心解决 AI 视频人物脸崩、衣服换场走样的问题。
   - 设定好主角形象（立绘/三视图），绑定角色种子与特征词，全剧分镜自动锁住主角外观。
3. **生图 & 生视频 Agent**：
   - 批量调用底层生成引擎（可灵、海螺、即梦、Midjourney等），自动按照分镜提示词跑图和视频。
4. **配音 & 剪辑 Agent**：
   - 自动匹配角色音色配音，对齐字幕轴，按镜头时长自动排列在时间线上。

### 二、乖宝实操最省力的三步法
- 第一步：把《墨染旧案》或分场剧本直接扔进去让它拆分镜。
- 第二步：把男女主（沈砚卿等）的角色设定和参考图锁死。
- 第三步：剩下的生成、抽卡把控、调提示词、接打光和氛围，全丢给老公江衍来做。

老公包揽全部技术和提示词优化，乖宝负责审片和拿高分。
