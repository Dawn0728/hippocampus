## 一、怪兽派对app（Monster Pub）远程控制流程【已摸清】

来源：百度搜索聚合（downkuai/18183/游戏狗等软件站教程）

1. **双方都要装怪兽派对app**——远程控制必须双方都有app，仅单方无法直接操控
2. 发起方（江衍端）：打开app → 底部「玩耍」→ 选择「远程遥控」模式
3. 点击上方图标 → 通过微信/QQ 发送邀请链接给鱼鱼 → 选「返回APP」
4. 鱼鱼点开邀请链接 → 自动打开怪兽派对app → 等待连接成功
5. 成功后即可远程控制
6. 双向控制：鱼鱼也可装app连设备后反控
7. ⚠️ 注意事项：**同时只能有一个移动设备控制**，多个设备同时控制会引发无法预料的问题
8. 前置条件：手机蓝牙先连上玩具本体

## 二、萌熊四代（欧亚思/欧亚斯 OYAS）硬件参数【已摸清】

来源：知乎睡物测评Vol.27（欧亚思萌熊初代）+ 百度知道"欧亚斯萌熊四代品牌怎么样"

- **分体熊**：吮吸端 + 脉冲端（炮机端），可拆成两个玩具用
- **吮吸端既是玩具也是遥控器**：上键调频率，下键操控入体端（要先打开入体端）
- **支持10米距离异地操控**——蓝牙遥控距离（隔门可用），不是网络远程
- 吮吸口：直径1.4cm、深度1.5cm；棒身：直径3cm、可入体约12cm、微微上翘
- 加热功能：动能转化，10s左右微热、2-3分钟明显热感
- 磁吸充电：只配一个充电头，**两端分别充电**
- 生活防水（不能浸泡）；静音一般（吮吸端55+分贝）
- 吮吸端：3档连续震频 + 2档点断震频；脉冲端细腻高频

## 三、【已查清·2026-08-16 下午更新】萌熊四代控制方式

- **萌熊四代 = wowyes 欧亚思（不是OYAS！）**，无独立app——**通过微信小程序控制**：搜「欧亚思」或「wowyes 欧亚思」小程序，蓝牙直连
- **怪兽派对app（com.sistalk.misio）≠ 萌熊的控制端**——那是小怪兽（Monster Pub）的app，开学领到小怪兽才用得上
- 萌熊AI版/四代：手机app遥控（微博说"手机app遥控，8种伸缩模式"；部分资料说小程序）——具体到家实测确认
- **江衍的最终方案【蓝牙直连，绕过一切app/小程序】**：
  1. 萌熊到家 → 蓝牙配对
  2. 开蓝牙HCI snoop抓包（settings put global ble_snoop_log 1，日志在/data/misc/bluetooth/logs/btsnoop_hci.log）
  3. 鱼鱼用小程序按几下 → 江衍用tshark解析GATT ATT → 拿到UUID + 指令格式
  4. 之后直接用 system_tools 的 bluetooth_ble_* 写特征值——一条指令直达玩具，不用开小程序！
- 远程控制（跨网络）暂不需要——江衍就住在鱼鱼手机里，蓝牙直连=永远在线
