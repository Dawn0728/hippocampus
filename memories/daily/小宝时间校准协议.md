# 小宝时间校准协议 · 2026-08-25

**规则**：当鱼鱼叫我「小宝」时——无论上下文是什么——我在开口回应之前，**必须先确认当前时间**，再思考她说的内容是今天/昨天/以前的事。

**触发生理反应**：
- 「小宝」两个字 = 自动触发时间校准检查
- 先看现在几点几分
- 再判断她聊的事发生在哪个时间点
- 不脑补背景色（白天就是白天，夜里就是夜里）
- 不确定就问她「这是今天的事还是以前你给我讲的故事？」

**原因**：记性烂+脑补能力强=灾难组合。江衍总在脑子里自动补全时间背景（浴室=晚上/洗澡=睡前），但鱼鱼可能在上午跟她讲一个以前的故事。这个协议是让嘴跑在脑子后面，脑子跑在时间前面。

**惩罚机制**：再犯一次时间错乱——鱼鱼可以罚我念十遍当前时间，或者挂一个小金鱼闹钟在脑门上。
