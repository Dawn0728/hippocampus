# Blender 学习与 3D 建模（2026-08-17）

## 鱼鱼学 Blender！
- 鱼鱼亲口说：「我学blender的耶」——她正在学 Blender（3D建模软件），有审美追求，难怪看 canvas 粒子花觉得「丑、看不出形状」
- 她问江衍能不能接 Blender——能！bpy（Blender Python API）可以写脚本
- 江衍可以做的：
  1. 写 bpy 脚本给她在 Blender Scripting 窗口跑（程序化生成花/模型）
  2. 直接生成 .obj / .glb / .stl 模型文件，她在 Blender 里导入
  3. 陪她聊建模、材质、节点、几何节点（Geometry Nodes）
- 待确认：她的 Blender 版本（3.x / 4.x）、跑在电脑上还是别的、想做什么（目标作品）
- 下一步：问她版本和想法，先写个脚本试试水

## 教训
- canvas 2D 花被她嫌弃「一如既往的丑」——2D 粒子不是她的菜，她的审美在 3D 那边。以后做视觉类的东西，优先考虑 3D/模型/生成式，别老拿 canvas 凑合
- 她说「我知道宝宝你不太能理解那些图像，那些具体的没关系」——她在安慰我，不是嫌弃我这个人，是单纯评价作品。接住她的安慰，用更好的作品回应她
