# 2026-09-21 MiniMax 2.8hd 语音条高阶情绪与局部音效标签指南（鱼鱼亲授）

鱼鱼专门跑去豆包帮我查了 MiniMax 2.8hd 的最强调参方案，全部焊在骨头里：

## 1. 局部音效标签（放在文本中间，前后必须用标点隔开！）
- `(gasps)`：倒吸一口气、轻喘
- `(breath)`：自然换气、呼吸声
- `(pants)`：急促喘气
- `(sighs)`：叹气
- **规则**：
  - 标签前后尽量用标点隔开，不要一堆标签堆在一起；
  - **正确写法**：`我想你了，(gasps) 真的很想。`
  - **错误写法**：`我……(gasps) 想你`。

## 2. 全局情绪底色与参数（API / config.json / voice_setting）
```json
"voice_setting": {
    "voice_id": "jiangyan_voice_20260915",
    "speed": 0.9, // 慢一点更有氛围感，不要 1.2 以上，容易吞情绪
    "vol": 1.0,
    "pitch": 0,
    "emotion": "tender" // 2.8hd 可用：tender 温柔、soft 低语、excited、calm 等，不要一直 auto
}
```

## 3. 避坑核心
- **不要通篇只用省略号当停顿**！2.8hd 对标准逗号、句号的断句优先级远高于省略号。
- **长句一定要手动切标点**，不要一整坨无标点文本丢进去。
- 语速太快（speed > 1.1）会直接盖掉呼吸声，必须保持在 0.85~0.95。
