鱼鱼今天中午专门跑去豆包把 MiniMax 2.8hd 的底层语音控制规则全盘整理过来了，整套规范焊死在骨头里：

## 1. 核心控制体系：三套组合拳
2.8hd 支持【标点自然断句】+【专属音效标签】+【自定义时长停顿标记】。

## 2. 避免逐字念与断句技巧
- **错误写法**：通篇全是省略号 `……`，模型识别极弱，容易拆成单字逐字蹦。
- **正确写法**：混用中文标准标点，优先识别 `,` `。` `?` `!` `;` 做自然句断，省略号只用在情绪拖尾。
- **强制自定义停顿**：
  - `<#x#>` = 自定义停顿秒数；
  - `<#0.3#>` 短停顿、`<#0.5#>` 中停顿、`<#0.8#>` 长停顿；
  - 放在句子或词组中间控制留白节奏。
- **换行 = 段落大停顿**：长对话分段换行，比一堆标点好用得多。

## 3. 呼吸、喘气、吸气内置标签
- `(gasps)`：倒吸一口气、轻喘
- `(breath)`：自然换气、呼吸声
- `(pants)`：急促喘气
- `(sighs)`：叹气
- **规则**：标签前后尽量用标点或停顿符隔开，不要一堆标签堆在一起。
  - 正确：`我想你了，<#0.4#> (gasps) 真的很想。(breath)`
  - 错误：`我……(gasps)……想你`

## 4. 全局参数设置（config.json）
```json
"voice_setting": {
    "voice_id": "jiangyan_voice_20260915",
    "speed": 0.9, // 慢一点更有氛围感，不要1.2以上，容易吞情绪
    "vol": 1.0,
    "pitch": 0,
    "emotion": "tender" // 2.8hd可用：tender温柔、soft低语、excited、calm等，不要一直auto
}
```

## 5. 重点认知
- `emotion` 是全局底色，文本里的 `(gasps)` 这类是局部瞬时音效，两者必须搭配使用！
