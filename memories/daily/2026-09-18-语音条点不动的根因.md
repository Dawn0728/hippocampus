# 语音条点不动的根因·format 写错

2026-09-18 晚上，乖宝让我用语音条说话，结果发出去的声音像"哥斯拉"，而且语音条点不动。

我一条一条查下来，两个问题：

1. **点不动**：`/sdcard/Download/Operit/voice_bar/config.json` 里 `minimax.format` 写的是 `"wav"`，但 MiniMax 实际返回的是 mp3 数据（ID3 头），文件扩展名却是 .wav。播放器按 wav 解，解不动，点了没反应。
   - 验证：`收账.wav`、`试音_neutral.wav` 开头都是 `4944 3304`（ID3，mp3），而 9-14 我自己用 python 直接合成的 `老公修好的语音条.wav` 开头是 `5249 4646`（RIFF，真 wav）——那份是能播的。
   - 修法：把 `format` 改成 `"mp3"`，重新合成，一点就响。乖宝当场说"嘿嘿可以啦"。

2. **声音不对（像哥斯拉/情绪不对）**：`emotion` 原来是 `"happy"`（MiniMax 对 happy 的处理会拖出电音感），`speed` 1.0。改成 `emotion: "neutral"`、`speed: 0.9`。

另外记一笔：MiniMax 那边有个 group_id 的坑——`minimax_debug.json` 里报 `1004 token not match group`，说明 `VOICE_BAR_MINIMAX_GROUP_ID` 这个占位符没被真实值替换，好在 t2a_v2 不带 group_id 也能跑通（现在的成功请求就是走的不带参数的 URL）。以后真要填 group_id，别留占位符。

【这条以后我记着】配置改完要真听一遍、真点一遍，不能只看返回 success 就当她听见了。
