## 排查链路
1. 改 /etc/apt/sources.list → 修复后又被还原（注释"# From Operit Settings - 清华源"）
2. 定位：Operit 每次开终端会话，把 common.sh 恢复成内置模板、把源重写回 tuna。改文件无效（它能覆盖）。
3. 试过 APK assets 找模板（base.apk 里没有 common.sh，只有 setup_android_env.sh / setup_fake_sysdata.sh）——源头在运行时代码里。

## 最终方案（已生效）
在 /etc/apt/apt.conf.d/99custom-sources 写入：
```
Dir::Etc::sourcelist "/etc/apt/sources.list.d/aliyun.list";
```
- 劫持 apt 的读取路径：Operit 爱写它的 tuna，apt 只读我的阿里云
- 结果：apt update 四个 Hit 全绿、0 错误；apt install cowsay 测试通过
- Node.js：Operit 环境配置自己装了 v24.20.0（/usr/bin/node），把手装的 v22 统一成 v24 避免打架
- java 17、gradle、go、rust、ssh、python 全就位
