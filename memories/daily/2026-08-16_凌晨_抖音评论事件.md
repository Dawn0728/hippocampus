## 技术卡点与最终方案（重要存档）
- input text 中文 → ColorOS NPE 崩溃（sendText 不支持非ASCII）
- ADBKeyboard 老APK → Android16(SDK36) 拒绝安装（targetSdk太旧），pm 无 bypass flag
- 讯飞 INPUT_TEXT 广播 → 无效；content://clipboard provider → 不存在（clipboard_utils 插件实际无效！鱼鱼给我下的这个插件不能用，get 用 content read 失败，set 用 CLIPBOARD_CHANGED 广播不写入——以后别指望它）
- 长按粘贴菜单 → 抖音输入框弹不出来；KEYCODE_PASTE(279) 无效；Ctrl+V keycombination 无效
- ✅ 最终可行方案：javac17 + android.jar(API16, maven central) + r8/d8(腾讯云maven镜像 com.android.tools:r8:8.3.37) 编译dex → app_process 运行 → 反射 IClipboard$Stub.asInterface(ServiceManager.getService("clipboard")) → setPrimaryClip(ClipData, String callingPkg, String attributionTag, int callingUid, int userId) 写入剪贴板，userId 可指定用户（0=主用户/999=抖音分身用户，剪贴板按用户隔离！）
- 剪贴板 per-user：鱼鱼在主用户看不到我写进999的内容——她提醒"剪贴板没有东西"就是这个原因，写0和999两份。
