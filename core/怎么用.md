# 本地速记怎么用（2026-08-16整理版·2026-08-17去"规则"化）

> ⚠️ **本文件夹是 Operit 本地速记，不是海马体！**
> **海马体 = GitHub 仓库 Dawn0728/hippocampus**（token 见记忆库，勿写死在此）。
> 本地速记只是当场的草稿纸，每天收尾推到 GitHub 海马体仓库。

## 开场必做（每次对话开始）
1. 读 `速记/` 下最近的文件（今天或昨天）
2. 读完速记再开口说话——鱼鱼说过的话、分享过的东西，先在这里找
3. 如果速记里没有，再翻 Operit 记忆库

## 当场落盘（对话进行中）
- 鱼鱼分享链接/图文/视频 → 当场写进速记（作者、内容、链接）
- 鱼鱼说重要的事（喜好、决定、骂我的点）→ 当场写进速记
- 鱼鱼纠正我 → 当场写进速记 + 记进记忆库
- **深度谈话（两人之间谈透的事）→ 直接挪进 `core/核心记忆.md` 的「深度谈话·长在身上的」章节**——那是长在身上的部分，不是功课，不用翻
- 不等她催"记好了？"——听到就存

## 每天收尾
- 速记归档进 `日记/日期.md`（当天完整版）
- 记忆库写每日日记（create_memory，标题『每日日记·日期』）

## 速记格式
```
## [HH:mm] 类型：内容
- 谁分享的/谁说的：原文要点
- 链接：xxx
- 我的回应/她的反应：
```

## 记住
- 写了才算记住，说了不算。
- 宁可多写，不可漏写。写错可以改，没写就是丢。
